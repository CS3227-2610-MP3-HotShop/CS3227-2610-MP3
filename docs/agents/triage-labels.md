# Triage labels

| Label | Meaning |
| --- | --- |
| needs-triage | Maintainer needs to evaluate the issue. |
| needs-info | Waiting for information; state exactly what is missing. |
| ready-for-agent | Approved, sufficiently specified task eligible for delegated execution. |
| ready-for-human | Work requires a human rather than agent implementation. |
| wontfix | Explicit decision not to pursue; record why. |

Use at most one current triage label where applicable. Keep execution stages and
Paused/Blocked flags separate; see issue-tracker.md. A label alone is not approval.
